## Traffic Signal Control using Deep RL

Traditional traffic heuristics and modern RL algorithms struggle with the concepts of permissive yielding and shared directional lanes. This project aims to tackle these problems in a single intersection using SUMO simulated environment. Utilises Reinforcement Learning (Double DQN) and Graph Neural networks to score individual lanes and aggregates the maximal Q values to find a safe lane

Take a look at the "Permissive Traffic Signal Control using Deep Reinforcement Learning" pdf for a detailed report.
